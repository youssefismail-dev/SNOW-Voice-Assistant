# ❄️ SNOW - Desktop Voice Assistant
​A personal learning project simulating popular voice assistants, built from scratch with my own touch to practice Python.

## ✨ Features
- **Voice Interaction:** Listens to your commands and responds.
- **Web Navigation:** Opens Google and YouTube via voice.
- **Information:** Searches Wikipedia and summarizes results.
- **Utilities:** Takes screenshots and saves them automatically.
- **Time & Date:** Tells the current time and date.

## 🛠️ Built With
- Python 3
- `SpeechRecognition` (For understanding voice commands)
- `pyttsx3` (For text-to-speech)
- `wikipedia`, `pyautogui`, and more.

## 🚀 How to Run
1. Clone this repository.
2. Install the requirements: `pip install -r requirements.txt`
3. Run the script:  python snow.py
4. Say "Hello SNOW!" ❄️
